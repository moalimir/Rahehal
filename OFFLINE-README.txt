نسخه آفلاین و پیش‌نمایش کامل راه‌حل

برای اجرای همه Routeهای واقعی و Deep Linkها در ویندوز، روی START-WINDOWS.bat دوبار کلیک کنید. مرورگر به‌صورت خودکار باز می‌شود و تا زمانی که پنجره اجرا باز است، فرم، ذخیره محلی، اعتبارسنجی، پیش‌نمایش و رسید کار می‌کنند.

فایل index.html نیز یک خروجی تک‌فایلی و مستقل است. آن را می‌توان مستقیماً و بدون Server باز کرد؛ Navigation این نسخه با Hash انجام می‌شود و فرم، Local Storage، Preview و Receipt فعال‌اند.
